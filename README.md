# A tool for building a glossary of linguistic characters

This is a project to play around with conlangs and writing systems. I wanted to be able to define the drawing approach taken for glyphs in an invented language and somehow convert these to images to be saved as part of a spritesheet.

The program in bridges user inputs and a glossary JSON file that persists all changes made in a session. This allows the user to create, modify, and delete characters in their glossary, and define their type, definition(s), and the series of brush strokes that make them up. Further options within a character are the modification of start/end stroke widths, the curve profile of the stroke from start to end, and stroke parentage which will play a part in character conjugation.
